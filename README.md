# 番茄钟 (Pomodoro Timer)

一个功能完整的番茄钟应用，帮助您提高工作效率和专注力。

## 功能特性

### 基本功能
- ✅ 25分钟专注模式倒计时
- ✅ 5分钟休息模式倒计时
- ✅ 开始、暂停、重置功能
- ✅ 时间结束时声音提醒
- ✅ 时间结束时弹窗通知

### 高级功能
- ✅ 自定义专注和休息时长
- ✅ 本地存储使用统计数据
- ✅ 每日、每周、总完成番茄数统计
- ✅ 最近7天完成情况图表展示
- ✅ 响应式设计，适配不同设备屏幕
- ✅ 优雅的动画效果

## 技术栈

- **HTML5**: 页面结构
- **CSS3**: 样式设计（响应式布局、动画效果）
- **JavaScript (ES6+)**: 核心功能实现
- **Chart.js**: 图表可视化
- **LocalStorage**: 数据持久化存储

## 使用方法

1. 直接打开 `index.html` 文件即可使用
2. 默认设置为25分钟专注，5分钟休息
3. 可以在"自定义时长"区域修改专注和休息时间
4. 点击"开始"按钮启动计时器
5. 点击"暂停"按钮暂停计时器
6. 点击"重置"按钮重置计时器
7. 完成一个番茄钟后会自动记录到统计数据中

## 数据存储

应用使用浏览器的LocalStorage存储以下数据：

1. **设置信息**：专注时长和休息时长
2. **统计数据**：
   - 总完成番茄数
   - 每日完成记录历史

## 响应式设计

应用支持以下设备：
- 桌面电脑
- 平板电脑
- 手机设备

## 浏览器兼容性

支持所有现代浏览器：
- Chrome (推荐)
- Firefox
- Safari
- Edge
