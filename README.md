# 🍅 番茄钟应用 (Pomodoro Timer)

一个功能完整的番茄钟应用，帮助您提高工作效率和专注力。

## ✨ 功能特性

### 基本功能
- **专注计时**: 25分钟专注时间倒计时
- **休息计时**: 5分钟休息时间自动切换
- **暂停/继续**: 随时暂停和继续计时
- **重置功能**: 一键重置计时器
- **声音提醒**: 计时结束时播放提示音
- **弹窗提醒**: 浏览器通知提醒

### 高级功能
- **自定义时长**: 可自由设置专注和休息时间
- **数据统计**: 记录每日完成番茄数和专注时间
- **图表展示**: 使用Chart.js生成7天统计图表
- **本地存储**: 使用localStorage保存设置和统计数据
- **响应式设计**: 适配桌面、平板和手机设备

## 🚀 快速开始

### 安装和运行

1. 克隆或下载项目文件
2. 直接在浏览器中打开 `index.html` 文件
3. 开始使用番茄钟！

### 使用方法

1. **开始专注**: 点击"开始"按钮启动25分钟专注计时
2. **暂停计时**: 点击"暂停"按钮暂停当前计时
3. **重置计时**: 点击"重置"按钮重置当前计时
4. **自定义设置**: 在"自定义时长"部分设置您喜欢的专注和休息时间，点击"保存设置"
5. **查看统计**: 在"使用统计"部分查看今日完成番茄数和专注时间，以及7天统计图表

## 🛠️ 技术栈

- **HTML5**: 页面结构
- **CSS3**: 样式设计（响应式布局、动画效果）
- **JavaScript (ES6+)**: 核心功能实现
- **Chart.js**: 图表生成
- **Web Audio API**: 声音提醒
- **Web Notifications API**: 弹窗通知
- **LocalStorage**: 本地数据存储

## 📱 响应式设计

应用支持以下设备：
- 桌面电脑 (1200px+)
- 平板设备 (768px-1199px)
- 手机设备 (320px-767px)

## 📊 数据统计

- **今日完成番茄数**: 记录当天完成的专注时段数量
- **今日专注时间**: 累计当天专注的总分钟数
- **7天统计图表**: 展示最近7天的番茄数和专注时间趋势
