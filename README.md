# 番茄钟应用 🍅

一个功能完整的番茄钟应用，帮助您提高工作效率，实现专注工作和高效休息的平衡。

## 功能特性

### 核心功能
- ⏱️ **25分钟专注 + 5分钟休息**：经典番茄钟工作法
- ▶️ **开始/暂停/重置**：完全控制您的工作节奏
- 🔔 **声音与弹窗提醒**：时间结束时的多重提醒方式

### 高级功能
- ⚙️ **自定义时长**：灵活设置专注和休息时间
- 💾 **数据统计**：记录您的番茄钟使用情况
- 📊 **可视化图表**：展示本周完成情况
- 📱 **响应式设计**：适配各种设备屏幕
- 💾 **本地存储**：设置和统计数据永久保存

## 技术栈

- **HTML5**：语义化结构
- **CSS3**：现代样式设计，渐变背景，动画效果
- **JavaScript ES6+**：核心功能实现
- **Chart.js**：数据可视化图表
- **LocalStorage**：本地数据存储

## 使用方法

### 基本使用
1. 打开 `index.html` 文件
2. 点击「开始」按钮启动25分钟专注计时器
3. 时间结束后会有声音和弹窗提醒
4. 自动切换到5分钟休息时间
5. 循环往复，提高工作效率

### 自定义设置
1. 在「自定义设置」区域调整专注和休息时长
2. 点击「保存设置」按钮
3. 新设置将在下次计时器启动时生效

### 统计功能
- 「今日完成」：显示今天完成的番茄钟数量
- 「总完成数」：显示所有时间完成的番茄钟总数
- 「周平均」：显示最近7天的平均完成数量
- 「本周图表」：可视化展示最近7天的完成情况

## 开发说明

### 本地运行
```bash
# 使用Python启动本地服务器
python -m http.server 8000

# 或使用Node.js
npx serve .
```

然后在浏览器中访问 `http://localhost:8000`

### 代码结构
- `init()`：初始化函数，加载设置和统计数据
- `startTimer()`：开始计时器
- `pauseTimer()`：暂停/继续计时器
- `resetTimer()`：重置计时器
- `updateStats()`：更新统计数据
- `initChart()`：初始化图表
